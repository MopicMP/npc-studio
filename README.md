# NPC Studio

Мод для Minecraft 26.2 (Fabric): NPC с диалогами, редактором диалогов прямо в
игре и анимациями.

## Сборка

```
./gradlew build
```

Нужен JDK 25. Gradle найдёт его сам, если он установлен — переменную `JAVA_HOME`
менять не требуется.

## Использованные материалы

### SPEmotes

Анимации персонажей — пак **SPEmotes**. Это чужая работа, и мод её только
воспроизводит: файлы включены как есть, без изменений.

- Сайт автора: https://spemotes.com/
- Boosty: https://boosty.to/spemotes

Пак распространяется автором свободно для некоммерческого использования; в мод
включена только та часть, что лежит в открытом доступе. Платные эксклюзивы с
Boosty сюда не входят. Если вы хотите поддержать автора — ссылка выше.

Формат файлов — EmoteCraft. Мод читает его же, поэтому свои анимации можно
положить рядом обычным ресурспаком, не трогая мод.

Пересобрать пак из архива:

```
python tools/extract_emotes.py "test/emotes/SPEmotes ALL.zip"
```

### Оговорка

Права на все сторонние материалы принадлежат их авторам. Если вы автор
использованного здесь материала и возражаете против его присутствия в этом
проекте — напишите, и он будет удалён немедленно.
